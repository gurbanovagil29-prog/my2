# Видео-пересказы книг — договорённости

Решения пользователя, которые действуют для всех книг, пока не скажет иначе.

## Форматы
- **YouTube** — горизонтальное видео 16:9, **без субтитров**.
- **Reels** (Instagram/вертикальные ролики) — 9:16, **с субтитрами в стиле «Яркий»**:
  Montserrat ExtraBold, ЗАГЛАВНЫЕ, белый текст с чёрной обводкой,
  текущее слово подсвечивается золотым (#FFC83C) и чуть увеличивается, короткие фразы по 3–6 слов.
  Шрифт: `tools/fonts/Montserrat-ExtraBold.ttf`.

## Рисовка
Стиль «графический роман» — см. `styles/STYLE.md` и `styles/styles.json`.
Бесплатный Pollinations этот стиль не тянет — нужен платный генератор (Flux и т. п.).

## Озвучка

Ключ хранится только локально в `~/.config/elevenlabs_key` (в git не попадает).
Переозвучку запускать только по команде пользователя (ограниченный лимит символов).

## Камера
Плавное движение (`tools/motion.py`): наезды, отъезды, панорамы с мягким разгоном,
переходы между сценами — перетекание (crossfade), без провалов в чёрное.

## Длительность
Эксперименты: 5, 10 и 15 минут. Язык — русский.
