# Сканер новостей → Telegram

Следит за ~25 лентами (российские СМИ, рынки, центробанки, мировые СМИ, крупная крипта),
отбирает важное и сразу присылает в Telegram. Опционально читает Telegram-каналы
в реальном времени, а они обычно быстрее сайтов.

## Шкала важности 0–10

| Балл | Смысл |
|---|---|
| 0–3 | шум, мелочь — не присылается |
| 4–5 | заметная новость |
| 6–7 | важная, пишут несколько СМИ |
| 8–9 | резкое событие, подхвачено многими СМИ |
| 10 | историческое событие (война, мирный договор, дефолт, экстренное решение ЦБ…), о котором пишут все |

Балл = тема (ключевые слова, максимум 6, растёт всё медленнее) + охват (сколько разных СМИ и как быстро, до +3,5)
+ бонус за историческое событие из строгого списка (`keywords.historic`). Одно СМИ даёт максимум 6,5;
10 бывает только у исторического события, о котором написали 5+ СМИ. Настройки — `config.yaml` → `importance`.

## Два канала

| Канал | Что приходит |
|---|---|
| 📰 **Лента** (`CHAT_FEED`) | всё от 3,5 баллов |
| ⚡ **Срочно** (`CHAT_URGENT`) | от 7 баллов, или **всплеск**: 3+ разных СМИ написали об этом за 30 минут (и от 5 баллов) |

Новость, ставшая «срочной» позже чем через 30 минут после первой публикации, в канал Срочно не идёт.
Если `CHAT_FEED`/`CHAT_URGENT` не заданы, оба канала шлют в `CHAT_ID`.
Проверить, сколько ушло бы в каждый канал за последние часы: `python -m scanner --once --hours 3`.

## Как он решает, что важно

1. **Ключевые слова с весами** (`config.yaml` → `keywords`): темы (Путин, санкции, ключевая ставка,
   Сбер, ФРС, нефть, Иран, Bitcoin ETF…), действия (повысил, запретил, одобрил…) и резкие события
   (мирное соглашение, отставка, дефолт, военное положение…). Действия и резкие события добавляют баллы,
   только если тема уже найдена.
2. **Подтверждение несколькими источниками**: одинаковые новости из разных СМИ склеиваются в одну историю
   и приходят один раз, а число СМИ повышает её важность.
3. **Чёрный список**: спорт, шоу-бизнес, погода и т.п. отбрасываются.
4. **Крипта**: из крипто-лент берутся только новости про BTC/ETH, ETF, SEC, регулирование и крупные события.
   Мемкоины, аирдропы, пресейлы и альткоины отбрасываются из любых лент.

## Быстрый старт

```bash
pip install -r requirements.txt
python -m scanner --once -v     # посмотреть, что прошло бы фильтр за последние 2 часа, с баллами
```

### Подключить Telegram-бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Напишите своему боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте свой chat id у [@userinfobot](https://t.me/userinfobot).
4. `cp .env.example .env` и впишите `BOT_TOKEN` и `CHAT_ID`.
   Для двух отдельных Telegram-каналов: добавьте бота в каждый канал администратором и впишите их id
   в `CHAT_FEED` и `CHAT_URGENT`.
5. `python -m scanner`

При запуске сканер присылает новости за последние 24 часа (`max_age_minutes`), а потом новые.
Что уже было отправлено, повторно не приходит: это хранится в базе `scanner.db`
(путь можно задать переменной `SCANNER_DB`, например на Google Drive в Colab).
В каждом сообщении указаны баллы (⭐) и слова, за которые они начислены.

### Telegram-каналы (быстрее всего)

Публичные каналы (MarketTwits, Раньше всех, ТАСС, РБК…) читаются через их веб-версию `t.me/s/<канал>`,
без входа в аккаунт. Список — в `config.yaml` → `telegram_channels`; добавить канал — дописать его имя из ссылки.

## Работа 24/7

Нужен любой VPS (от ~300 ₽/мес). Варианты запуска:

**Docker:**
```bash
mkdir -p data && sed -i 's|^db_path: scanner.db|db_path: data/scanner.db|' config.yaml
docker build -t news-scanner .
docker run -d --restart=always --env-file .env -v $PWD/data:/app/data --name news news-scanner
```

**systemd** (`/etc/systemd/system/news-scanner.service`):
```ini
[Service]
WorkingDirectory=/opt/news-scanner
ExecStart=/usr/bin/python3 -m scanner
Restart=always

[Install]
WantedBy=multi-user.target
```

## Настройка

Всё в `config.yaml`:
- слишком много уведомлений → поднимите `thresholds.send` или уберите общие слова;
- что-то важное не приходит → добавьте слово или источник;
- `python -m scanner --once -v` показывает баллы и найденные слова для каждой новости, этим удобно подбирать веса.

Тесты: `pytest`.
