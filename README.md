# Telegram-бот для пересылки сообщений

Бот пересылает все сообщения (текст, фото, видео, документы, стикеры и т.д.)
из указанных чатов-источников в один или несколько чатов-получателей.
Работает с личными сообщениями, группами и каналами.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости:
   ```bash
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен бота;
   - `SOURCE_CHAT_IDS` — ID чатов, откуда пересылать (пусто — из всех);
   - `TARGET_CHAT_IDS` — ID чатов, куда пересылать;
   - `MODE` — `forward` (с пометкой «Переслано от…») или `copy` (копия без автора).
4. Запустите: `python bot.py`

## Как узнать ID чата

Добавьте бота в чат и отправьте команду `/id` — бот ответит ID этого чата.
Для каналов перешлите любой пост канала боту [@userinfobot](https://t.me/userinfobot)
или временно добавьте канал без фильтра и посмотрите ID в логах.

## Важно

- **Группы:** чтобы бот видел все сообщения, отключите у него Privacy Mode
  (@BotFather → Bot Settings → Group Privacy → Turn off) или сделайте его администратором.
- **Каналы:** бот должен быть администратором и в канале-источнике, и в канале-получателе.
- **Получатель — личный чат:** пользователь должен сначала сам написать боту `/start`.
- Если в источнике включён запрет на копирование (protected content),
  пересылка не сработает ни в одном режиме — это ограничение Telegram.
